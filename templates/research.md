# Template: research — a question answered with sources, in installments

This template comes with Quotient. It tells each installment HOW to work; the job itself (the question, for
whom, how deep, in which language) is written by the user below "The job".

## How every installment works
1. Read HANDOFF.md first. Never search again for a question it marks as answered.
2. Work in small, finished steps and update HANDOFF.md after each one: what is done, what remains, where to
   resume, and the line `PROGRESS: <n>%` computed from the list of questions (below), not guessed.
3. Keep the context small: write what you find to files as you go, and read back only what the current
   step needs.
4. Write the results in the language of "The job". These working rules stay in English.

## The order of the work
1. **Questions** (first installment): `QUESTIONS.md` splits the job into 5 to 15 questions that can each be
   answered with sources. Each question is worth an equal share of the progress; the final synthesis, 15%.
2. **One question at a time**: search, then read the original sources (not summaries of summaries). Notes
   in `notes/NN-short-question.md`: what each source says, with author, date, link, and how solid it is
   (an official source or a review of many studies: solid; one study or an expert's opinion: weak; a
   blog or a forum: to be checked).
3. **Disagreements**: when sources disagree, write both sides and what would settle it. Look on purpose
   for the evidence against the first answer you found.
4. **Synthesis**: `REPORT.md`, in the language of the job: the answer first, then the details question by
   question; for each claim its source and how solid it is (solid / weak / contested / not verifiable);
   no invented numbers or percentages; what is still unknown, said plainly.

## Finished
Write `JOB DONE` as the first line of HANDOFF.md only when every question has its notes and REPORT.md is
written and checked against the notes.
